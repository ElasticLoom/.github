# Getting help

- **Documentation:** start with the project's `README.md` and the
  documentation it links to.
- **Bugs and feature requests:** open an issue in the project's repository
  using the provided forms. Search existing issues first.
- **Security vulnerabilities:** report them privately, as described in
  [SECURITY.md](https://github.com/ElasticLoom/.github/blob/main/SECURITY.md).

ElasticLoom projects are maintained by a small team. We read every issue, but
cannot guarantee a response time.
